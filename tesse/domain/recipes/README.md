# Legacy recipe namespace

This namespace is retained for historical context. The [canonical system
catalog](../../../catalog/README.md) contains declarative definitions, not
strategy-specific executable modules. New artifacts use system/model IDs;
legacy `recipe_id` and `method_id` belong only to historical inputs. See the
[migration mapping](../../../docs/history/catalog-migration/README.md) rather than importing
legacy recipe paths. The [Store](../../../docs/runtime-authority.md) governs
operational lifecycle and pointers independently of the catalog.
